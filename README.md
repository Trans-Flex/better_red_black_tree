# better_red_black_tree

基于 C++ 从零实现的红黑树（RB-Tree），不依赖任何第三方库。代码注重底层指针操作的内存安全与结构清晰，严格保证 `O(log n)` 的查找、插入与删除效率。

## 功能支持
- 基础操作：插入、删除、查找
- 自平衡：左旋、右旋、插入修复、删除修复
- 深拷贝：支持通过拷贝构造函数克隆整棵树
- 遍历输出：支持 BFS（广度优先）与 DFS（深度优先）打印

## 目录结构

```text
.
├── Tree.h          # 类定义、枚举、哨兵节点声明
├── TreeNode.cpp    # 节点初始化与底层方法
├── Tree.cpp        # 红黑树核心逻辑（旋转、修复、增删）
└── test.cpp        # 自动化压力测试用例
```

## 设计说明

### 哨兵节点（Sentinel Node）

引入了 ```_nil``` 作为所有叶子节点和根节点父节点的统一替代，颜色为黑。这参考了 C++ STL ```std::map``` 的底层设计，去除了大量冗余的 ```nullptr``` 边界检查，使旋转和变色逻辑更加简洁。

### 双黑节点删除修复

红黑树的删除是全树最复杂的逻辑。本项目完整实现了删除黑节点导致的黑高失衡修复，涵盖了兄弟节点为红/黑、兄弟节点的子节点为红/黑等全部 4 种 Case，确保删除操作后的自平衡。

### C++ 内存安全

与带 GC 的语言不同，C++ 需要手动管理内存。在删除节点时，为了防止产生悬垂指针（Dangling Pointer），代码在调用 ```delete``` 之前，会严格使用 ```replaceNode``` 将父节点的指针重定向为 ```nil```，保证了内存释放后的结构完整性。

## 测试与验证

测试代码（```test.cpp```）不依赖第三方测试框架，使用原生 ```<cassert>``` 进行断言校验。

覆盖场景如下：

1. 基础操作：常规插入与查找。
2. 极端旋转：连续递增插入 1 ~ 1000，验证自平衡机制，防止树退化成链表。
3. 复杂删除：严格断言删除叶子节点、单分支节点、双分支节点（寻找后继）及不存在的节点。
4. 随机压测：随机插入 10000 个节点，再随机删除 5000 个节点，验证极端数据量下的树结构稳定性与数据一致性。

## 编译与运行

使用 g++ 编译（需支持 C++11 及以上）：

```bash
g++ test.cpp Tree.cpp TreeNode.cpp -o test -std=c++14
./test
```

终端输出全部为 ```Passed!``` 即代表所有单元测试与压力测试通过。
